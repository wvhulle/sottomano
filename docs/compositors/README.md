# Compositors

Sottomano runs on niri, sway and Hyprland, and finds the running one from
`NIRI_SOCKET`, `HYPRLAND_INSTANCE_SIGNATURE` or `SWAYSOCK`. The same
[configuration](../configuration.md) works on each compositor; the pages below
cover what each one offers the bar, starting the session and including the
window styling rules sottomano writes.

- [niri](niri.md): everything the bar offers works, including the overview and
  column moves.
- [sway](sway.md) and [Hyprland](hyprland.md): what they do not offer.
