## Player

One group per MPRIS player. Scrolling on the group seeks.

| Indicator | Press | Popup |
|---|---|---|
| Track | bring the player's window forward | metadata, playback and search links |
| Position | jump to that point | |
| Shuffle, Previous, Play or pause, Next, Stop | the matching control | |
| Quit | quit the player, after confirming | |
| Lyrics | | synced lines (`panel_menus.media.media.lyrics`) |

## Audio

Scrolling on the group changes the output volume.

| Indicator | Press | Popup |
