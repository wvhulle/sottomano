# Windows and workspaces

Workspace previews, the window list and what runs behind each window.

## Workspaces: Previews

Hovering a workspace shows its windows.

<img src="https://codeberg.org/wvhulle/sottomano/raw/branch/recordings/bottom_workspaces.webp" width="519" alt="Hovering a workspace in the bottom panel">

## Applications: Frequent apps

The rocket before the window list opens the installed applications. The first group ranks apps by launches on the current workspace, or across all workspaces on an unnamed one. An app with an open window has a button on the right of its row that focuses its most recently used window.

<img src="https://codeberg.org/wvhulle/sottomano/raw/branch/recordings/app_launcher_frequent.webp" width="1005" alt="Frequently launched apps with a hover card and open window buttons">

## Applications: Categories

Every other app is listed under its freedesktop category. A list grows up to the height of the screen and scrolls when it does not fit, fading at an edge with rows beyond it.

<img src="https://codeberg.org/wvhulle/sottomano/raw/branch/recordings/app_launcher_overflow.webp" width="682" alt="A scrolled application list fading at both edges">

## Windows: Directory groups

Neighbouring terminals in one directory share a heading, with the selected window in the accent colour.
