# Windows and workspaces

Bottom panel. The window list sits in the middle; the workspaces sit in a sidebar, or on the left of the bottom panel when the Workspaces sidebar setting is off.

| Element | Press | Popup |
|---|---|---|
| Workspace | | previews of its windows |
| Window | focus the window | title, app id and last focus |
| Process inspector | | the process tree behind the window |

Neighbouring terminals in one directory share a heading unless Group windows by directory is off in the Panels settings.
