# Power

Top panel, right. A list of the actions logind allows, grouped by family; it is hidden when logind allows none. An entry notes when idle triggers it or when it asks for authorisation.

| Family | Entries |
|---|---|
| Locking | Lock, Lock all sessions, Screen off |
| Sleeping | Sleep, Suspend, Hibernate, Hybrid sleep, Suspend then hibernate |
| Shutdown | Reboot, Reboot into firmware setup, Reboot into boot menu, Halt, Power off, Cancel scheduled shutdown |
| Session | Log out, Terminate session, Restart shell |
