## [0.1.0](https://codeberg.org/wvhulle/sottomano/releases/tag/v0.1.0) - 2026-11-20

### Added

- top panel, bottom panel, optional workspace sidebar and notification toasts in one binary
- compositor support for niri, sway and Hyprland
- widget groups for compute, memory and board, weather, audio and media, wallpaper, windows and workspaces, idle and session, AI usage, network, virtualization and CI runs
- one TOML configuration file whose complete default the shell prints
- home-manager and NixOS modules
